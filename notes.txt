Quick reminders

1. app = FastAPI()          → create app OBJECT from FastAPI CLASS
2. @router.get("/")        → DECORATOR (attach URL to function)
3. __init__.py             → optional package marker (3.3+ namespace packages OK)
4. __init__ method         → different thing: class constructor

7. common/                 → DATABASE_URL + engine + get_db
8. services/               → DB operations (list/get/create)
9. routers/                → HTTP only; call services
10. docker compose up -d   → Postgres on localhost:5433
